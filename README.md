## Что реализовано

1. **Яндекс Карты.** На главной находится виджет Яндекса с центром в Москве. При построении маршрута в Яндекс передаётся список точек в заданном порядке и пешеходный режим. Есть ссылки для открытия полной навигации в Яндекс Картах. Виджет не является API для ручного редактирования точек; редактирование происходит в полях сайта.
2. **Моё положение.** По нажатию кнопки сайт запрашивает разрешение браузера, устанавливает координаты в качестве начальной точки и обновляет карту. Для GPS нужен HTTPS и разрешение на геопозицию. Координаты не сохраняются автоматически.
3. **Схема прогулки.** После построения справа видна последовательность «старт → остановки → финиш», ссылки на пешую навигацию между соседними точками и оценка расстояния по прямой, когда известны координаты. Точные километры, время в пути и фактический маршрут по дорогам рассчитывают Яндекс Карты: CityRoute не выдаёт оценку по прямой за пешеходный километраж.
4. **Остановки и фотографии.** Мгновенный локальный каталог московских мест, фильтры, поиск, добавление до трёх остановок. Каждая карточка имеет кнопку «Фото / отзывы» в Яндекс Картах. Подтверждённые фотографии из Wikimedia/Wikipedia подгружаются при наличии таких источников; чужие изображения не выдаются за фотографии заведения. Карточки загружают фотографии лениво, чтобы не тормозить телефон.
5. **Круговой маршрут.** Финиш совпадает со стартом, при необходимости создаются промежуточные ориентиры и передаются Яндексу; реально доступный пешеходный путь проверяй в Яндекс Картах.
6. **PostgreSQL.** База Supabase (PostgreSQL 17) содержит 90 московских объектов, таблицы маршрутов, избранного, настроек и аккаунтов. В публичных таблицах включена RLS. Сохранение в облако требует входа в аккаунт и явного действия пользователя; без него маршруты остаются в браузере.
7. **Интерфейс.** Переключение RU/EN и светлой/тёмной темы, бюджет, тип прогулки и дополнительные предпочтения.

## Ограничения и безопасность

- Не используется базовая карта OpenStreetMap и не загружаются её тайлы. Библиотека Leaflet осталась в служебной части исходников, но подложка видимой карты — только Яндекс.
- Без ключа Yandex JavaScript API нельзя синхронизировать клики и перетаскивание маркеров внутри iframe с полями CityRoute. Встроенная карта может зависеть от блокировщиков или региональной доступности Яндекса; отдельная ссылка на Яндекс сохранена.
- Привязать подлинное фото к **каждому** кафе без разрешённого источника/поставщика фотоданных невозможно. При отсутствии подтверждённого фото показывается ссылка на фотогалерею конкретного места, не случайная картинка.
- Каталог является стартовым и не гарантирует часы работы/доступность заведения. Запрос фотографий Wikimedia, геокодирование неизвестных адресов и доступ к PostgreSQL зависят от сторонних сервисов.
- Настройки на этой бесплатной статической версии не вызывают настоящий GPT; подсказки обрабатываются локально.

## Проверки

Автоматическая GitHub Actions сборка `Build and publish CityRoute` проверяет JavaScript и тесты, экспортирует `site-src/` в `docs/`, после чего запускает браузерные проверки на мобильном размере экрана: GPS, Яндекс-виджет, поиск мест, карточки, схема прогулки, сохранение, круговой маршрут и ввод другого города. Тест использует подставной ответ карты Яндекса, а потому не может подтвердить поведение реального внешнего виджета в конкретном браузере. Тесты PostgreSQL и RLS находятся в `site-src/tests/` и отдельном workflow.
