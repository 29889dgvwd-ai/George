## Исправления ноября 2026

- Основная интерактивная карта показывает маршрут **сразу на карте**, а не прячет синюю линию под бесплатным iframe Яндекса.
- Круговой маршрут, старт и финиш (необязательный), выбранные остановки, кнопка нового варианта, длина и бюджет.
- Добавлен резервный расчёт пешеходного пути через OSRM при отказе Valhalla (если сервисы недоступны, вместо ложного маршрута показывается ошибка).
- Карточки остановок и изображения по проверяемым ссылкам OpenStreetMap / Wikimedia Commons / Википедии, если они существуют. У каждой остановки — переход в Яндекс Карты для просмотра фотографий и отзывов. Без согласованного API Яндекса массовый импорт его фотографий не делается.
- Кнопка «В Яндекс Картах» открывает маршрут с выбранными остановками. Карта внутри CityRoute — OSM/Leaflet, чтобы отображать точно построенную линию.
- Сохранённые прогулки можно открывать в `walks.html` без сервера. Светлая/тёмная тема и RU/EN.
- В статической версии нет серверной авторизации и GPT: текстовые пожелания обрабатываются локальными правилами без имитации работающего ИИ; «Друзья» содержит понятное объяснение и ссылку на обмен маршрутом.

## Проверки
GitHub Actions `Build and publish CityRoute` автоматически запускает синтаксическую проверку JS, существующие тесты маршрута/остановок, экспортирует сайт и публикует его в `docs/` при каждом изменении в `site-src/`.

**Ограничения:** без платных ключей бесплатные источники мест, фотографий и пеших маршрутов иногда недоступны или ограничивают запросы. Отсутствующие фотографии не заменяются чужими. Проверены сборка, JS-синтаксис и программные тесты; полноценный сценарный прогон на реальном телефоне остаётся необходим.

> Старый домен `cityroute-walk-map.gbfksjhxmm.chatgpt.site` не обновляется этими GitHub Actions. Перенос на новый адрес через GitHub Pages не требует менять исходники.
